# YJ-learning-with-AI

낯선 산업(통신·반도체)을 AI와 함께 학습한 기록의 원본 공개 저장소.
질문·지시 원문 47건과 정정 19건 전량을 CSV로 발행한다. 잘된 것만 고르지 않았다.

**3분 요약은 [발행 페이지(index.html)](index.html)에서.** 이 README는 아카이브 전체를 안내한다.

## 이 저장소의 한계 — 먼저 적는다

이 기록의 가치는 규모가 아니라 부풀리지 않았다는 사실에서 나온다.

1. **커밋 이력은 발행일 이후만 증명한다.** 발행일 이전의 날짜는 파일 메타데이터와 본인 진술 기반이며, 전 항목에 신뢰도 3등급(확정/추정/불명)을 표기했다. 날짜를 만들어 넣지 않았다.
2. **반도체 학습 기간은 10일이다.** "몇 달간 공부했다"가 아니다 — 방법론이 5개월, 반도체 적용이 10일.
3. **편집은 두 종류뿐이다.** 타사 지원 맥락의 회사명을 'A사'로 치환했고, 생활 정보 3곳을 대괄호로 마스킹했다 (규칙 전문: `docs/methodology.md` 6장). 반말·이모티콘·오타·틀린 추론을 포함한 나머지는 원문 그대로다.
4. **빈 칸은 빈 칸으로 남겼다.** 재적용 미확인 8건은 미확인으로 표기했다. 채워지는 순간마다 커밋으로 기록한다.
5. **일부 전형 정보는 3차 소스(커뮤니티 속보) 기반이며 "재확인 필요"로 표기했다.** 이 표기는 삭제하지 않는다.

## 이 저장소는 계속 자란다

다음 기록 예정: 모의과제 A 실전 풀이(정정 A01~A04 재적용의 자연 발생 지점), 신규 영역 진입 시 L1→L3 측정 (`docs/methodology.md` 4-2 프로토콜).

갱신 커밋은 `log:` 접두어를 쓴다 — 예: `log: A03 reapplied (mock-task-a)`. 이력은 `CHANGELOG.md`.
